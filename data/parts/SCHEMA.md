# 種データ スキーマ（厳守）

出力先は `data/parts/<グループid>/<ファイル名>.json`。ビルド（`node scripts/build-species.mjs`）が検証してマージします。

各種は以下の形の JSON オブジェクト。配列としてファイルに書き出す。

```json
{
  "id": "dendrobates-tinctorius",
  "nameJa": "アイゾメヤドクガエル",
  "nameSci": "Dendrobates tinctorius",
  "nameEn": "Dyeing Poison Frog",
  "family": "ヤドクガエル科",
  "familySci": "Dendrobatidae",
  "sizeMm": [40, 50],
  "description": "南米ギアナ地方の熱帯雨林の林床に生息する大型のヤドクガエル。青・黄・黒の派手な体色は個体群ごとに大きく異なり、多数のモルフが知られる。飼育下では餌由来のアルカロイドを摂取しないため毒を持たない。国内の動物園・水族館で最もよく見られるヤドクガエルのひとつ。",
  "tags": {
    "habitat": ["地表棲"],
    "origin": "国外",
    "size": "中型",
    "activity": ["昼行性"],
    "toxic": true,
    "region": ["南アメリカ"],
    "breeding": "雨季（3〜8月）",
    "redlist": "低懸念(LC)"
  },
  "zooDisplay": true
}
```

## 各フィールドの規則

- `id`: 学名を小文字ハイフン区切りにしたもの（例 `rana-japonica`）。半角英数字とハイフンのみ。一意。
- `nameJa`: 和名（カタカナ）。定着した和名がない場合は学名由来の通称を作り、末尾に「（仮称）」は付けない。
- `nameSci`: 学名（属名 種小名）。斜体記号などは付けない。
- `nameEn`: 英名。無ければ学名を再掲せず、一般的な英語通称を書く。
- `family`: 科の和名（例「アカガエル科」「ナミヘビ科」「リクガメ科」）。
- `familySci`: 科の学名（例 `Ranidae`）。
- `sizeMm`: `[最小mm, 最大mm]` の整数2要素。成体のサイズで、**測り方はグループごと**（下表）。オス/メス差があるなら全体のレンジ。
- `description`: 日本語 80〜160字。生息環境・見た目の特徴・生態・（該当すれば）日本の動物園水族館での展示状況に触れる。事実として確からしいことだけ書く。
- `tags.habitat`: **グループごとの語彙**から1〜2個（下表）。
- `tags.origin`: `在来` / `外来` / `国外` のいずれか1つ。
  - `在来` = 日本に自然分布する種
  - `外来` = 日本に定着した国外由来の種（ウシガエル、シロアゴガエルなど）
  - `国外` = 日本に分布しない種
- `tags.size`: **書かなくてよい**（ビルドが sizeMm の最大値とグループの基準から機械的に決め直す）。
- `tags.activity`: `夜行性` / `昼行性` / `薄明薄暮性` から1〜2個。
- `tags.toxic`: 真偽値。カエル・イモリ・サンショウウオは皮膚毒（毒腺・アルカロイド・テトロドトキシン等）を持つなら true。
  ヘビは有毒種（コブラ科・クサリヘビ科・ヤマカガシなど）が true。トカゲはドクトカゲ類などが true。
  カメ・ワニ・ヤモリは常に false（ビルドが強制的に false にします）。
- `tags.region`: 次の語彙から1〜3個 →
  `日本` / `東アジア` / `東南アジア` / `南アジア` / `中央アジア` / `西アジア` / `ヨーロッパ` / `アフリカ` / `マダガスカル` / `北アメリカ` / `中央アメリカ` / `南アメリカ` / `オセアニア` / `カリブ`
  （日本産種は必ず `日本` を含める）
- `tags.breeding`: 繁殖期（カメ・ワニは産卵期）を短い日本語で（例 `4〜6月`, `1〜3月（早春）`, `雨季`, `通年`）。不明なら `不明`。
- `tags.redlist`: 次のいずれかの文字列 →
  日本産種は環境省レッドリスト区分: `絶滅危惧IA類(CR)` / `絶滅危惧IB類(EN)` / `絶滅危惧II類(VU)` / `準絶滅危惧(NT)` / `情報不足(DD)` / `評価対象外` / `ランク外`
  国外種は IUCN 区分: `絶滅危惧IA類(CR)` / `絶滅危惧IB類(EN)` / `絶滅危惧II類(VU)` / `準絶滅危惧(NT)` / `低懸念(LC)` / `情報不足(DD)`
- `zooDisplay`: 真偽値。**日本の動物園・水族館・爬虫類ショップやイベントで実際に見られる種なら true**。国内で見る機会がほぼない種は false。

## グループ別の語彙とサイズ帯

| グループ (id) | sizeMm の測り方 | habitat の語彙 | サイズ帯の境目(mm) | toxic |
|---|---|---|---|---|
| カエル (`frog`) | 吻肛長 | 樹上棲/地表棲/地中棲/水棲/半水棲/流水性 | 25 / 50 / 90 / 150 | あり |
| イモリ (`newt`) | 全長 | 同上 | 70 / 110 / 160 / 250 | あり |
| サンショウウオ (`salamander`) | 全長 | 同上 | 60 / 120 / 250 / 600 | あり |
| ヘビ (`snake`) | 全長 | 樹上棲/地表棲/地中棲/岩場棲/砂漠棲/水棲/半水棲 | 400 / 800 / 1500 / 3000 | あり |
| カメ (`turtle`) | **甲長** | 陸棲/淡水棲/汽水棲/海棲/半水棲 | 120 / 200 / 400 / 800 | なし |
| ヤモリ (`gecko`) | 全長 | 樹上棲/地表棲/地中棲/岩場棲/砂漠棲/水棲/半水棲 | 80 / 120 / 200 / 350 | なし |
| トカゲ (`lizard`) | 全長 | 同上 | 120 / 250 / 500 / 1500 | あり |
| ワニ (`croc`) | 全長 | 淡水棲/汽水棲/半水棲 | 1500 / 2500 / 4000 / 6000 | なし |

境目は「未満」で区切り、下から 超小型 / 小型 / 中型 / 大型 / 超大型。

**グループの切り分け**（重複させない）:
- イモリ = 有尾目のうち**イモリ科 (Salamandridae)**。ファイアサラマンダーもここ。
- サンショウウオ = 有尾目のイモリ科以外（オオサンショウウオ科・サンショウウオ科・トラフサンショウウオ科・アメリカサンショウウオ科・サイレン科など）。
- ヤモリ = ヤモリ下目（ヤモリ科・トカゲモドキ科・イシヤモリ科・ヒレアシトカゲ科など）。
- トカゲ = 有鱗目からヘビ亜目とヤモリ下目を除いた残り（スキンク・アガマ・イグアナ・カナヘビ・オオトカゲ・カメレオンなど）。

## 品質ルール

- **確実でない数値をでっち上げない**。体長は文献的に妥当なレンジを書く。
- 種の重複を出さない（担当科の外の種は書かない）。
- 出力はコメントなしの純粋な JSON 配列のみ。
